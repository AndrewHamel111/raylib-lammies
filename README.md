# raylib CLion Template

This is a very basic project template for raylib using CMake and has been tested with CLion.

The raylib source code is included in the libs folder as it is much easier than including prebuilt binaries for every platform and configuration. That source is an unmodified copy of raylib 6.0, however it can be modified as needed for the project.
